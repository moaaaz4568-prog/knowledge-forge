# G_yt_T8FIYJE0Y2E_en — compound path

## Term

Here a compound path is the Illustrator function that groups objects together so an effect or a function can be shared among them: a compound path essentially groups objects together and allows an effect or a function to be shared among those objects. The phrase appears 15 times, beside "Illustrator", "function", "functions", and "groups", in a video about the compound path functions you need to know. In the speaker's use the compound path is what lets you edit the cut-outs after the fact: select three circles with a gradient across each of them, unite them in the Pathfinder window, and they are grouped together as one shape while the gradient remains the same throughout the three circles — and with the direct selection tool you can edit a cut out section or move the circles around. His concrete commands are the shortcuts: command or control 8 for the compound path itself, and holding alt or option to turn a Pathfinder cut into a compound path instead of a normal one, so the cut stays editable.
