# G_yt_Srs5_EwTK8M_en — logo

## Term

Here a logo is judged by the file behind it: the first hallmark of an amateur logo designer is that the logo file itself will have excess anchor points, shapes that are not united, and strokes that are not expanded, which causes issues when scaling the logo up or down. The word appears 16 times, beside "amateur", "designer", "file", and "professional", in a video that asks what makes a logo designer amateur or professional. In the speaker's use the file is the evidence: the actual logo file will not be named or labeled properly, while a professional logo designer will always correctly label each logo file with a relevant name and maybe even a date. The same standard runs through the other points — refining choices down to two to four designs for the client, and choosing a font that relates back to the message — because the professional's work is tidy all the way down to the file.
