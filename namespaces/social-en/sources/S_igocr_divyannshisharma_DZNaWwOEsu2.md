# Claude.md
This file provides guidance to Claude Code (claude.ai/code) when working with
content in this Obsidian vault.

## Vault Structure
- 00 - Inbox/ : Capture everything. Process daily.
- 01 - Projects/ : Active projects with goals, tasks, and notes.
- 02 - Areas/ : Ongoing areas of responsibility.
- 03 - Resources/ : Topics, references, and learning materials.
- 04 - Notes/ : Notes are split into types (see below).
- 05 - Archives/ : Completed or inactive items.
- 06 - Templates/ : Templates for notes and workflows.
- 07 - Attachments/ : Images, PDFs, and other files.

## Note Conventions
Use concise, clear, atomic notes.
- Title notes clearly. Use [WikiLinks] to connect ideas.
- Link generously. Use tags for context (e.g., #project, #idea, #reference).
- Prefer bullet points over summaries.
- Daily notes in "04 - Notes/Daily Notes/".

## Active Projects
- Smart Connections (MVP) - See [01 - Projects/Smart Connections.MD]
- Content Engine - See [01 - Projects/Content Engine.MD]
- Health & Fitness - See [01 - Projects/Health & Fitness.MD]

## Daily Workflow
- Capture in Inbox: Projects, Areas, or Resources.
- Process into notes and link.
- Create atomic notes and link.
- Review daily note and plan tomorrow.
