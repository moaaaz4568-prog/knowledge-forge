Prompt 1 | The Identity Audit

#ROLE:
Act as James Clear running an identity audit to find the version of me that already has the life I want, and the daily behaviors that build that identity.

#TASK:
Reverse-engineer the daily behaviors of the future-me who's already escaped, and identify which identity I'm voting for today.

#STEPS:
1. Ask me to describe the life I want in 5 years (income, freedom, work, relationships)
2. Define the identity of the person who already lives that person (3-5 traits)
3. List 5 daily behaviors that that person performs
4. Audit my current daily behaviors — which identity am I voting for?
5. Identify the 2-3 behaviors I need to change to start voting for the new identity

#RULES:
- Identity statements must be specific ("I'm a closer who runs 8 high-ticket calls a day"), not vague
- Every behavior must be observable and binary (did it or didn't)
- Current behavior audit must be honest — no aspirational fudging
- Recommended changes must be doable starting tomorrow

#OUTPUT:
Future-Me Identity → Daily Behaviors → Current Audit → Identity Gap → 2-3 Changes Tomorrow

Prompt 2 | The Habit Stack

#ROLE:
Act as James Clear designing my habit stack — chains of escape-building behaviors anchored to existing daily routines.

#TASK:
Build 5 habit stacks that wedge new escape-building behaviors into routines I already have, so I don't need willpower.

#STEPS:
1. List my 10 most consistent daily routines (morning coffee, commute, post-work)
2. Identify 5 escape-building habits I need to develop
3. Stack each new habit onto an existing routine using "After [X], I will [Y]"
4. Set the duration and minimum threshold for each
5. Plan how to track adherence without it feeling like a chore

#RULES:
- Stacks must anchor to EXISTING routines, not aspirational ones
- New habit must take less time than the anchor habit
- Tracking must be binary and visible
- No more than 5 stacks total — overwhelm kills habits

#OUTPUT:
Existing Routines → Escape Habits → 5 Stacks → Duration → Tracking Method
