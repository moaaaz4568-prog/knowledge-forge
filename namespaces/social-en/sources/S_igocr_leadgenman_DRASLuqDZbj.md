LlamaIndex

A data framework that connects LLMs to external data by loading, indexing, and retrieving from 150+ sources and vector stores, enabling retrieval-augmented generation.

Key Features:
• Supports 150+ data sources (PDFs, SQL, APIs)
• Integrates with 40+ vector databases
• Query transformation splits complex queries into smaller, manageable parts
• Strong at search and retrieval tasks
<!-- image 4 -->
RAGFlow

An open-source, self-hosted RAG framework focused on document ingestion, parsing, and grounded answering with visual citations across formats like PDFs, Excel, and web pages.

Key Features:
• Open-source, self-hosted framework (My personal favorite)
• Advanced document understanding
• Visual breakdown of citations
• Handles Word, Excel, images, and web content
<!-- image 5 -->
Haystack
A production-oriented NLP/LLM framework by deepset for building RAG and QA pipelines with components for indexing, retrieval, generation, and serving via REST.
Key Features:
• End-to-end pipeline builder from Deepset AI
• REST API available out-of-the-box
• Works with Elasticsearch/OpenSearch
• Technology-agnostic (OpenAI, Hugging Face, Cohere)
• Offers pre-built pipelines for quick development.
<!-- image 6 -->
LangGraph
Graph-centric extension built on LangChain for structured, relationship-aware retrieval over knowledge graphs. This framework is useful for apps that require complex data relationships.
Key Features:
• Efficiently retrieves data from graph structures.
• An extension of LangChain for graph databases
• Works with interconnected data structures and retrieves context from intricate relationships
