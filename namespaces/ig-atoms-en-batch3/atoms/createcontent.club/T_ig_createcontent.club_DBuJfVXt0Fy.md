# T_DBuJfVXt0Fy_01

"Here's how to create this blur font effect. Add your text on top of the video and make sure to choose a simple font. Now what you want to do is add a blur effect when the text appears. To do so, add a keyframe at the beginning and set the blur to a high value. Then move a few keyframes forward and set it back to zero. To make the effect even smoother, let's fade it in and out too." — sources/S_ig_createcontent.club_DBuJfVXt0Fy.md

# T_DBuJfVXt0Fy_02

"Add a keyframe for opacity and set it to zero at the beginning. Move a few frames forward and set it back to... one hundred. Now do the same exact thing but the other way around before the text disappears to make it fade out and you're done. If you want a tutorial on how to recreate the same effect on CapCut too, just comment 'blur'." — sources/S_ig_createcontent.club_DBuJfVXt0Fy.md
