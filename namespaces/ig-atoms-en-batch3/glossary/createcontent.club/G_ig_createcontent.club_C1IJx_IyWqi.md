# G_ig_createcontent.club_C1IJx_IyWqi — screenshot

## Term

Screenshot is the single action this clip asks of creators: capture the frame, because the links it promises live behind a comment, not in the video itself. The word appears once, in you need to screenshot this, next to create content and comment create. The clip is a twenty-one-word pointer, not a lesson — it names no tool and teaches no method, only the instruction to save the frame or comment for the links. A creator following it would screenshot the frame and comment create to receive all the links in DM.
