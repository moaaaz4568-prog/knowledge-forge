# G_ig_nicolasboucherfinance_DWBgdxQkdLL — Canvas

## Term

Canvas here is the hidden tool for turning a finished analysis into a dashboard in HTML, which almost nobody knows about. The word appears once, beside reporting, dashboards, plus button, dashboard in HTML, and BI team, and the video's contrast is the time: this saves so much time, and it is much more efficient than letting a BI team work on it for three months. His concrete move is to activate it by clicking the plus button, and once done with the analysis, ask AI to create a dashboard in HTML that uses the analysis to create the dashboard — and of course review it. Canvas is the tool you activate after the analysis, not before it.
