# G_ig_nicolasboucherfinance_DXKREC9CWFe — prompt

## Term

Prompt here is the instruction behind each of six finance jobs, handed over six times in a single menu of a video. The word appears six times, once per job, beside five year financial forecast, dynamic dashboard for cost reviews, executive dashboard, cash flow dashboard, three statement model, and compiling Excel files, and each job gets the same treatment: name the need, then "Here's the prompt." The video itself is only the menu, pointing to a masterclass next Tuesday for more use cases. The prompt is the unit of work — one instruction per job, not one instruction for everything.
