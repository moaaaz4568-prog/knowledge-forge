There are three levels to creating a viral Instagram series! First up, the level number one series—you create a series name and the series kind of just consists of posts that all revolve around the same common topic.

Each video is posted in a different format. Each of the episodes in the series closes the loop completely by the end of the video, and you post a new episode whenever you feel like it.

Level number two series—it has one clear goal or mission the series builds around. It uses a repeatable series name and states the episode number every video.

It uses one format to film each video and keeps that the same across the entire series. Every episode is about a real update, a lesson, progress on the goal, etc., and the posts are on a predictable rhythm so followers know when the next one drops.

And lastly, every episode closes the loop by the end of the video.

Level number three series—similar to level number two, it has a mission, a series name, and it films in the same format. But for level number three, they restate the mission in every single episode.

They add stakes and name the consequence if the goal is not reached. It picks a series type and structures their series, whether it's a daily series, a progress update series, a lessons series, step-by-step series, etc.

It builds the series towards a real finale so there is an ending event or milestone that has to be reached, and it treats each episode like a chapter that all add up together.
