# G_ig_rawaa.aljallad_DD9NhQMO_QE — Insert link

## Term

Insert link عند رواء خيار في جيميل يحوّل رابطاً طويلاً إلى كلمة صغيرة تبين في رسالتك، فتكبس عليه فيطلع لك بوكس تضع فيه الكلمة في الفراغ الأول والرابط في الفراغ الثاني. يظهر المصطلح مرة واحدة في المصدر، محاطاً بـ«Insert Hyperlink» و«Ctrl K» و«Apply». استعمالها مقارن: في جيميل تكبس Insert link ثم Apply، وفي أوتلوك تكبس Attach File ثم Insert Hyperlink وتضع الرابط عند Address ثم OK، ومن يحب الاختصارات يكبس Ctrl K أو Command K فيطلع له نفس الصفحة. هكذا يصير المصطلح عندها أداة تجميل للروابط في الرسائل، لا أداة مشاركة روابط.

## Synonyms

- Insert Hyperlink (الاسم الذي يستخدمه Outlook في المصدر)

## When the Meaning Breaks

- حين يُقرأ Insert link كاختصار رابط: المصدر يشرح تحويل رابط طويل إلى كلمة صغيرة تظهر في الرسالة، لا تقصير الرابط نفسه.
- حين يُفهم أن الطريقة واحدة في كل تطبيق: رواء تفرّق بين جيميل وأوتلوك — في الأول Insert link ثم Apply، وفي الثاني Attach File ثم Insert Hyperlink ثم OK — والاختصار Ctrl K أو Command K طريق ثالث.
