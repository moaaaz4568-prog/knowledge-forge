# T_3pwnpxd3uhU_02

"عندما أقول انشر، أعني إرسال بريد إلكتروني، أو نشر شيء ما على فيسبوك، أو البث المباشر، أو مشاركة محتوى يوميًا، أو مشاركة أي شيء مع العالم." — sources/S_yt_3pwnpxd3uhU.md

# T_3pwnpxd3uhU_04
