# G_yt_JjUx_1m6Hvs_en — command

## Term

In this Illustrator tips video, command is the Command key, and the lesson is the shortcut it unlocks. The word command appears 8 times, next to object, shape, and align, as the speaker walks through useful hacks: select a shape and split it into a grid with Object Path Split into Grid, use the Align tool from a chosen object, and keep guides unlocked so they can align artwork. The star tip is the repeat: if you hit Command D, or Control D on the PC, you will perform your most previous action, so resizing a shape and hitting Command D resizes it in the same way again. Command here is therefore not an order but a key, and the hack is the time it saves.
