# G_yt_JFai8IzN-3k_en — file

## Term

In this Illustrator tutorial, file is the saved format a logo is exported in, and the lesson is choosing the right one for each job. The word file appears 32 times, next to logo, design, format, and save, as the speaker works through PDF, JPEG, PNG, and EPS. With JPEG there is no choice for a transparent background, and it is lossy, so he teaches the save for web option and the view PDF after saving setting, and his last tip is to package all of the logo files into one zip folder because it reduces the file size when sending them. A file here is therefore not the artwork itself but the container it travels in, and the format decides what the client can do with it.

## When the Meaning Breaks

- Read as the design itself, file confuses the container with the content: here a file is the saved format, PDF or JPEG or PNG, and the same logo lives in many files.
- Read as a single document, it misses the workflow: the speaker saves three different PNGs from one export and packages all the logo files into one zip folder.
