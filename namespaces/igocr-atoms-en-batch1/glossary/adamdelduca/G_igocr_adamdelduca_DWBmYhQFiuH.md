# G_igocr_adamdelduca_DWBmYhQFiuH — YouTube Toolkit

## Term

In this carousel, "YouTube Toolkit" is a tool map for maximizing income, split into four shelves: "NICHES" with "TUBELAB" and "NEXLEV", "TOPICS" with "VIDIQ" and "SUBSCRIBR", "PRODUCTION" with "VIDRUSH" and "TUBEGEN", and "THUMBNAILS" with "PIKZELS" and "CANVA". It appears once, in the heading "YouTube Toolkit (to maximize income)", and every tool sits under exactly one job. The map's point is coverage: each stage of the pipeline gets two named tools to choose from. A reader copying it would pick one tool per shelf instead of stacking several tools that do the same job.
