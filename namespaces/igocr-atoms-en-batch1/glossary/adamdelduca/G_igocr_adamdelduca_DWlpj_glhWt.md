# G_igocr_adamdelduca_DWlpj_glhWt — YouTube Automation Workflow

## Term

In this carousel, the "YouTube Automation Workflow" is a $20,000-a-month pipeline that pairs five tools with four jobs: finding top paying niches, drafting quality scripts, generating voiceovers and creating engaging thumbnails. It appears once, in the heading "$20,000/mo YouTube Automation Workflow", and the tools named are "NexLev", "SubscribrAI", "ElevenLabs", "CapCut" and "Pikzels". The workflow's point is the order: niche first, then script and voice, then thumbnail, with each tool handing off to the next. A reader copying it would run the same tools in the same order instead of starting with the thumbnail.
