# G_igocr_adamdelduca_DVBVYNrkT79 — YouTube Automation Roadmap

## Term

In this post, the "YouTube Automation Roadmap" is a six-step sequence for reaching "$10,000/mo" with an automated channel. It appears once, heading steps that pair each tool with one job: "TubeLab" selects niches, "VIDIQ" picks topics, "Subscribr" drafts scripts, "ElevenLabs" generates voiceovers, "Capcut" edits videos and "Canva" creates thumbnails. The order is the method — niches before topics, topics before scripts, scripts before voice, voice before editing, editing before thumbnails — so each step consumes the previous step's output. Someone following the roadmap would work through the six tools in that order and treat the "$10,000/mo" label as the destination the sequence is meant to reach.
