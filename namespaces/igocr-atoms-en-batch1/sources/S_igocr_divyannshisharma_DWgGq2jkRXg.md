The Models: What You're Working With
There's three model tiers
Opus 4.6 — Best quality, highest cost ($5/$25/M tokens). Use for complex, high-stakes, one-off tasks. Don't use for anything you run repeatedly.
Sonnet 4.6 — The default for most people ($3/$15/M tokens). Fast, capable, 40% cheaper than Opus. Start here and only upgrade if needed.
Haiku 4.5 — Cheapest and fastest. Good for high-volume API pipelines. Avoid in agentic setups with untrusted input — no prompt protection.
Default to Sonnet. Escalate to Opus only when quality demands it. Use Haiku only when volume and cost matter most.

Honest Limitations
Cowork eats your usage fast.
It burns usage fast
One complex session = dozens of regular chats. Pro users hit limits in 3-4 days of daily use. Mid-task cutoffs are brutal.
Monitor Settings > Usage. Heavy users need Max (100-200/mo).
Context compaction hits long sessions
Claude auto-summarises earlier parts to save alive. Numbers get rounded, file details go vague. If it says "typical patterns" instead of your actual file keys — compaction already happened.
Tell Claude to write key findings to a file as it goes.

CLAUDE.md: Your
Project's Instruction

Loads straight into system prompt.

Put this:
- Exact build/test/lint commands
- Key architecture decisions (e.g. monorepo, Turborepo)
- Non-obvious rules & gotchas (strict TS, edge cases)
- Coding conventions (imports, naming, error handling)
- Project structure (important folders/files)
- Always include the "why" behind the rules

Don't put:
- Linter/formatter configs
- Long docs or theory
- Anything obvious or already documented
- Over 200 lines (too long = worse output)

The CLAUDE.md Hierarchy
There are four layers that merge
1. Managed Policy (org-wide): IT deployed. Cannot be overridden. Organization-wide rules.
2. ~/.claude/CLAUDE.md (global): Your personal preferences across all projects. Not version controlled.
3. /CLAUDE.md (project root): Team instructions. Committed to git. Everyone who clones the repo gets these.
4. CLAUDE.local.md (personal project context overrides): Your personal tweaks for this specific project. Automatically gitignored.
