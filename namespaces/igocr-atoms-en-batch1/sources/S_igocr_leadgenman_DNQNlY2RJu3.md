CUSTOM CODE NODE

The Custom Code node lets you write JavaScript directly inside n8n to handle data in ways that built-in nodes can't. Transform, filter, and manipulate data, build advanced conditions, or even call external APIs all without leaving your workflow.

Key Capabilities:
Data Access: Use $input.all() to work with all incoming items.
Node-Specific Data: Access any node's output with $node["NodeName"].json.
Built-in Libraries: Includes Lodash, Moment, and Axios for powerful scripting.

AI AGENTS NODE

The AI Agents node enables large language models to not just respond but plan, decide, and act within your workflows. It connects LLMs to tools, APIs, and data sources, creating fully autonomous task execution.

Key Capabilities:

Autonomous Decision-Making: Agents decide the best next step without manual input.
Tool Integration: Seamlessly use APIs, databases, and third-party services.
Context Awareness: Retains relevant information for accurate, multi-step execution.
