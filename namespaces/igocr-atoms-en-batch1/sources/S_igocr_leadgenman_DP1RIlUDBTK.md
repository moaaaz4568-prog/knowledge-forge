4 main components that form the

Workspace, Node, Trigger, and
Flow.
Let’s break them down.
<!-- image 1 -->
What is a Workspace?

“Workspace = the main canvas where you build your automation.”

Think of the workspace like your digital work desk. This is where you arrange nodes, visualize automation sequences, and manage everything visually. Without the workspace, you’d have no place to build your flow.
<!-- image 2 -->
What is a Node?

“Node = a function block. Each has a specific task.”

Examples: HTTP Request, Send Email, Google Sheets, Discord.
You simply drag & drop, configure inputs and outputs, and n8n executes them one by one in order.
<!-- image 3 -->
What is a Trigger?

“Trigger = the starting point of an automation.”

The trigger defines when or what event starts the automation. Examples include a schedule (Cron), a new email, or a webhook. Without a trigger, your flow will never begin.
<!-- image 4 -->
What is a Flow?
"Flow = the full sequence of steps from start to finish."
A flow is a complete automation made up of a trigger, several nodes, and a final action. Example: A form is submitted → the data is recorded → an email is sent automatically.
<!-- image 5 -->
How They Work Together
Trigger → Node → Flow. All inside the Workspace.
Workspace = the container
Trigger = the starting point
Node = the steps
Flow = the end-to-end process
