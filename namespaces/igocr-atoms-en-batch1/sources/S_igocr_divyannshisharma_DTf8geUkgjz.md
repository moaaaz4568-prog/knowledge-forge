Phase 1:
n8n?
What is n8n?
Core Architecture
n8n is a free, open-source automation tool that connects apps, services, and AI agents without heavy coding.

Trigger Nodes:
• Start workflows
• Lightning icon is automatically identifier
• Can be scheduled or event-based
• Support multiple trigger types
• Essential for workflow initiation

Action Nodes:
• Perform operations in workflows
• Execute tasks sequentially
• Process and transform data
• Connect to external services
• Chain multiple actions together

Tool Nodes:
• Connect to external services
• Optional AI agent execution
• Integrate with APIs
• Enhance workflow capabilities
• Support custom workflow integrations

n8n Cloud vs Self-Hosted
Instant Setup:
• No configuration required, automatic updates, and managed infrastructure for immediate productivity.
Full Control:
• Self-hosted option provides complete environment control, custom configurations, and enterprise-level security.
Cost Involved:
• Cloud uses subscription pricing while self-hosted is free with infrastructure costs - choose based on your budget.
Maintenance:
• Cloud offers automatic updates and maintenance, self-hosted requires manual updates but provides greater flexibility.
Security:
• Cloud is managed by n8n, self-hosted gives complete data control - ideal for sensitive enterprise requirements.
Use Cases:
• Cloud for quick start and convenience, self-hosted for enterprise security, customize, and data ownership.

Phase 2:
Workflow Data
Fixed vs Expression Values

Every node processes data through input and output panels
Fixed values are static and hardcoded, remaining the same for every execution. Expression values are dynamic, using JavaScript syntax to pull data from previous nodes. Fixed: "Send an email" | Expression: {{ $json.chatInput}}

Strings
Text data like "hello world" - used for messages, names, and descriptions

Numbers
Numeric values (42, 3.14, -100) - for calculations, counts, measurements

Booleans
True/false values - for conditional logic and decision making

Arrays
Lists of data [1, 2, 3] - for multiple items and iterations

• Understanding data types ensures smooth workflow execution and proper data handling.

Context vs Vector
How AI Remembers
Context Memory (Short-term)

• RAG stores external document embeddings as searchable knowledge base for large repositories
Without Memory
• Agent forgets previous interactions and cannot maintain conversation context or recall earlier information
With Memory

Phase 5:
API Integration Basics
Understanding Web Requests

GET Method
• Retrieve data from servers – used for fetching information without modifying resources

POST Method
• Send data to create new resources – used for form submissions and data creation

PUT Patch
• Update existing resources – PUT replaces entirely, PATCH modifies partially

DELETE Method
• Remove resources from servers – used for deleting records and data cleanup

Authentication
• Header Auth, OAuth2, or API keys – secure your requests and protect sensitive data
