# G_yt_8m6Akr-BHsg_en — favicon

## Term

A favicon is short for a favorite icon: a very simplified, very small icon that represents a brand or business, found in the browser address bar, tabbed browsing, and bookmark lists. Its goal is to make the internet friendlier to the end user — if you are a brand or have a portfolio website, a favicon makes the user feel more welcome and more secure. The word appears 16 times in the source, beside design, small, brand, and browser, with the plural favicons 6 more times. His concrete rule is size: the standard desktop browser favicon is 32 by 32 pixels, in PNG, with a transparent version and a solid background version, since some applications need transparency and others, like Apple touch and Android, use a color background.

## When the Meaning Breaks

- Read as decoration: a favicon makes the user feel more welcome and more secure, and must reflect the brand's identity in a single small design.
- Read as one file fits all: different sizes and formats are needed per application — transparent for desktop browsers, color background for Apple touch and Android.
