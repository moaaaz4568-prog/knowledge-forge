# G_yt_8awJexLg658_en — gradient

## Term

A gradient is the color blend the tutorial adds to text in Illustrator without outlining it, so the wording stays editable afterward. Default text is standard, not outlined, so a gradient applied directly just stays the same color — black, in the demo — and the fix is a compound shape made through the Pathfinder menu, after which the gradient tool edits the blend. The word appears 8 times in the source, beside text, typography, tool, and Pathfinder. His concrete setup is the font Antoniou, bold version, with the gradient tool locked by pressing G to control how far each end of the colors runs across the gradient.

## When the Meaning Breaks

- Read as outlining the text: the whole point is not outlining, so the text stays editable — outlining would freeze the wording.
- Read as a fill color: a gradient is a blend across the text, with ends of the colors running across it, not a flat color applied once.
