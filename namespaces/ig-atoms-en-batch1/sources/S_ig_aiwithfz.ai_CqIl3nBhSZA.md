How can overfitting be avoided when building a decision tree model? Pre-pruning: This involves setting constraints on the tree's maximum depth, the minimum number of samples required at a leaf node, or the minimum impurity decrease for a split to occur. Post-pruning: This involves growing the tree to its maximum size and then pruning the tree by removing nodes that provide little information gain. Ensemble methods: Using ensemble methods like random forests, bagging, or boosting can help reduce the impact of overfitting by combining multiple trees. Cross-validation: Using techniques like k-fold cross-validation can help identify overfitting by evaluating the model on multiple independent data sets.
