Common techniques for handling imbalanced classes in logistic regression, and how do they work? Oversampling: randomly replicating instances of the minority class to balance the class distribution. Undersampling: randomly removing instances from the majority class to balance the class distribution. Synthetic Minority Over-sampling Technique (SMOTE): creating synthetic instances of the minority class to increase its size while maintaining its distribution. Class weighing: assigning a higher weight to the minority class to increase its importance during model training.
