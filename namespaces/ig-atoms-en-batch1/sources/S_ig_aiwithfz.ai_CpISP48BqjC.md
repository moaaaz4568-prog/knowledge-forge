What is ridge regression? Ridge regression is a type of linear regression with a regularization term added to the cost function. The regularization term helps to reduce the variance of the coefficients and prevent overfitting. The amount of regularization is controlled by a parameter, called the regularization parameter, that determines the trade-off between the fit to the data and the size of the coefficients. Ridge regression is especially useful when there are a large number of predictors in the model or when the predictors are highly correlated. Ridge regression is similar to lasso regression, another type of regularization technique, but it uses a different penalty term that includes the absolute value of the coefficients.
