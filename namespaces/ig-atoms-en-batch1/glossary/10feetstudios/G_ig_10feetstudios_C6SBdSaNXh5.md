# G_ig_10feetstudios_C6SBdSaNXh5 — done with you

## Term

Done with you is the second half of the speaker's service-delivery shift: move work from done for you to done with you and add a consulting aspect to the agency. The phrase appears twice, both times paired with "done for you", and the concrete case is appointment setting — instead of booking appointments for clients, the agency scripts out the clients' own appointment setting sequences. The same move covers funnels: building a funnel for every client takes too long at scale, so the agency teaches clients to do it themselves with videos and resources.

## Synonyms

- No variant form of the term appears in this source.

## Live Example

> "So you should move these aspects from done for you to done with you and create videos and a lot of resources showing them how they can do these things for themselves." — sources/S_ig_10feetstudios_C6SBdSaNXh5.md

## When the Meaning Breaks

- Read as abandoning delivery: the content side (editing, posting) stays fully done for the client; only the parts that don't scale move to teaching.
- Read as a cheaper package: he presents it as a model change for scale, not a discount — the client still pays while learning.
