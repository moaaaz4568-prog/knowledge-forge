# G_ig_airesearcherguy_CLNZCGiHTkZ — QR code

## Term

A QR code is Chrome's automatic gift in this source: click the URL of any page — an Etsy product, an Amazon listing, a digital product — and Chrome has already generated one for it. The phrase appears four times, beside Chrome, Etsy, Amazon, and keyword embedded URL. The speaker's amazement is that no tool is needed: the browser creates the code for the page you are already on, for e-commerce products and anything else.

- No variant form of the term appears in this source.

## Live Example

> "Chrome automatically creates a QR code for a page." — sources/S_ig_airesearcherguy_CLNZCGiHTkZ.md

## When the Meaning Breaks

- Read as a feature of the store: the QR code is generated by Chrome for the page, not by Etsy or Amazon for the product.
- Read as a paid tool: the speaker presents it as something Chrome does automatically, with no extension or purchase involved.
