Never use statements when you're selling. Instead, use questions. Let me give you an example. When someone tells you, "How do I know if this is gonna work for me?" If you use a statement, you can say something like, "Well, it has worked for hundreds of our clients. We've worked with many in this industry, and I'm sure that we can help you." This is a statement. The conversation is now frozen, and you have to do a lot of pushing and convincing, which it triggers sales resistance, really doesn't get the job done. But if you start using questions, for example, "Well, if it has worked for hundreds of our clients, why do you feel it wouldn't work for you though?" That puts the responsibility back on them, and now they will try to defend their position and start selling themselves, instead of you trying to do all the work.
