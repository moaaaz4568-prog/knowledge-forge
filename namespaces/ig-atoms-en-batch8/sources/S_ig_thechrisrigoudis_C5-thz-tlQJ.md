My other favorite question to ask when you're on sales calls is "What else would you change?" The reason why this is so potent and powerful is because it allows the prospect to brainstorm more problems. People won't tell you the truth the first time you ask them something. The first problem that they give you will probably be superficial or something very surface level. So when you ask them, "What else would you change though?" Now you're getting to the core problem, to the root problem they really care about solving, which brings you closer to the truth, so you can craft the perfect solution for them.
