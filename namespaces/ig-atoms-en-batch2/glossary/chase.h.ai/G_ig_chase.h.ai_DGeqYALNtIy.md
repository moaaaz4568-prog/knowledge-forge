# G_ig_chase.h.ai_DGeqYALNtIy — hybrid LLM

## Term

In this source, hybrid LLM is what Claude Sonnet 3.7 is: the first hybrid LLM on the market, doing both the fast quick responses Claude is known for and the long drawn-out thinking responses seen with DeepSeek and O1. The phrase appears 2 times, beside Claude, coding, and thinking, and the speaker says the combination puts Claude back on top as the best coding model in the game. His concrete case is the stats: best marks for software engineering accuracy against ChatGPT and DeepSeek, and higher marks than ChatGPT's o1 for agentic tool use. Claude also announced Claude Code the same day, an agentic coding tool in preview for complex, high-workload software engineering tasks.
