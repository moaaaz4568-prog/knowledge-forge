# G_ig_chase.h.ai_DJRshaVx5Y2 — MACD chart

## Term

In this source, a MACD chart is the example chart the speaker pulls in part two of the stock-agent guide: on the chart-image site he picks the MACD chart shown with Microsoft, then makes it dynamic so it pulls whatever chart he wants. The phrase appears once, beside curl, HTTP request, and API key, because the part is the plumbing — copy the curl code, import it into the HTTP request module, add the API key, set the response format to JSON, and pass the ticker as a query. His concrete case is the Tesla test, where the edited fields show symbol, NASDAQ, and the ticker, and pasting the URL shows the chart itself.

- No variant form of the term appears in this source.

> "So for this example, we're gonna use this MACD chart and it shows it with Microsoft, but we're gonna change it so it's dynamic and it pulls whatever chart we want." — sources/S_ig_chase.h.ai_DJRshaVx5Y2.md

## When the Meaning Breaks

- Read as analysis itself: the MACD chart is only the picture the agent will analyze in part three, so grabbing it is setup, not the analysis.
- Read as a Microsoft-only chart: he picks the Microsoft example only to make it dynamic, so a chart fixed to one ticker would miss the point of the part.
