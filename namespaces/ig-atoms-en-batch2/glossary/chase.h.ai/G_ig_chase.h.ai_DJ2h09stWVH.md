# G_ig_chase.h.ai_DJ2h09stWVH — Lovable

## Term

In this source, Lovable is the no-code front end the speaker pairs with N8N to build web apps: treat it like ChatGPT, give it a prompt, and it creates the web page — his demo is a cover letter creator that takes a name, target company, position, and extra information. The name appears 8 times, beside N8N, webhook, and cover letter creator, and the split is fixed: Lovable builds the page the user sees, N8N runs the back end, and webhooks move the data between them. His concrete case is the cover letter creator, where Lovable sends the form data to N8N, the agent synthesizes it and researches the company, and the finished letter comes back through a webhook.

## When the Meaning Breaks

- Read as the whole app: Lovable only builds the front end — the research and letter writing happen in the N8N agent — so a page with no back end would not be the app he demos.
