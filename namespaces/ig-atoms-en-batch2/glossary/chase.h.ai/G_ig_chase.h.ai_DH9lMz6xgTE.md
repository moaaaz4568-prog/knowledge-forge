## Term

In this source, MCP is the protocol the speaker wires into his N8N server so his AI agents can use the latest tools: the Model Context Protocol, set up in 60 seconds. The term appears 8 times, beside N8N, server, and tools, and the setup needs self-hosting first, then the N8N nodes MCP package from community nodes, then an environment variable allowing community packages to use tools. His concrete case is the Airbnb test: the MCP client lists available tools from the Airbnb server — Airbnb search and listing details — with no API key needed. The command is npx with arguments copied one by one, and the speaker points to the MCP GitHub and the N8N MCP client GitHub for the deeper directions.
