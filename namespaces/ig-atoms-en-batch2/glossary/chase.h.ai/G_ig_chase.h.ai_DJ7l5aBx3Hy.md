# G_ig_chase.h.ai_DJ7l5aBx3Hy — AI agent

## Term

In this source, an AI agent is what the speaker builds from scratch in about two minutes inside n8n.io: search for AI agent to get the skeleton, hook up a chat model — OpenAI's 4. 1 mini, a cheap version of a good model — add simple memory for the last five messages, then add tools for Gmail and Reddit. The phrase appears 6 times, beside chat model, simple memory, and Reddit, and the finished agent sends emails, searches Reddit, and combines the results into a message. His concrete case is the live test, where he asks for the top five posts from the ChatGPT subreddit with summaries emailed to him.

## When the Meaning Breaks

- Read as a polished product: the test email comes out with ugly formatting he would fix by editing the system message, so a rough first output is still the agent working.
- Read as instant expertise: the two-minute build is a very simple agent, so expecting it to handle sophisticated work would overstate what he built.
