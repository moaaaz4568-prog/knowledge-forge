# G_ig_chase.h.ai_DJcVdeSxu7p — AI agent

## Term

In this source, an AI agent is what the speaker explains and demos for the non-technical user: the bones are the ability to talk with it, a chat model as the brains — GPT 4o or o3 — simple memory so it remembers, and tools for sending emails, looking things up, and creating in Notion. The phrase appears 10 times, beside chat model, simple memory, and Airtable, and the hardest part is only connecting accounts, which takes a few minutes. His concrete case is the contact list, where the agent figures out who to email from a database and then records every sent email in Airtable.

## Synonyms

- AI agents (the plural form the speaker uses)

## When the Meaning Breaks

- Read as just ChatGPT: the model plus chat plus memory is only the base — without tools it cannot send mail or record anything — so the base alone is not yet the agent he demos.
- Read as a coder's tool: every step is a click — add a chat model, add memory, add tools — so needing code to build one would contradict the demo.
