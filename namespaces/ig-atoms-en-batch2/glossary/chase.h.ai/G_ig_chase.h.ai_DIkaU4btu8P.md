# G_ig_chase.h.ai_DIkaU4btu8P — AI agent

## Term

In this source, an AI agent is what the speaker builds inside N8N without code: start on a blank canvas, add a chat model like ChatGPT's 4o mini, add simple memory so it remembers conversations, then add tools — and the agent, unlike an automation, does different things based on what he tells it. The phrase appears 7 times, beside chat model, simple memory, and tools, and the build takes about 45 seconds on screen. His concrete case is the Reddit task: search the top post on an AI subreddit, summarize it, make a content outline for a video, email it to him, and create a Notion page.

## Synonyms

- AI agents (the plural form the speaker uses)

## When the Meaning Breaks

- Read as an automation: an automation does the same thing every time, while his agent picks different tools per request, so a fixed single-path workflow is not an AI agent here.
- Read as a coder-only build: he builds the whole thing in 45 seconds on a canvas with no code, so needing programming skill to make one would contradict the demo.
