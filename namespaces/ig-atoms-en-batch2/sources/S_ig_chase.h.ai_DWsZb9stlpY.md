If you want to run a graph RAG system in your local environment, then these are the two GitHub repos you should be using in parallel. Now the first one is LightRAG, and this is what lays the foundation for our graph RAG system. Completely open source, the only downside for using LightRAG is the fact that the only sort of documents it can ingest are text. So no images, no charts, no graph, text only. But that's where RAG Anything comes in. Same makers as LightRAG, and you use RAG Anything as a wrapper around LightRAG, and it allows you to send those non-text documents through a RAG Anything tunnel, and it's going to extract all the text it can. It's going to push the images to get OCR'd, and in the end, you get a graph RAG system that gets the best of both worlds. Completely open source.
