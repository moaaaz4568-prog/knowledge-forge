My top three reasons that I enjoy using kettlebells, not only for myself but also with clients, and that first one being for front loading. So front loading meaning holding the weight in front of the body. You know, obviously this is something that can be done with the dumbbell, can be done with the barbell, but I find that the shape of the dumbbell as well as wrist flexibility on the barbell make it a little bit more challenging. And so that kettlebell just kind of fits perfectly for a lot of people. And I think the process of having to actually create that tension and squeeze that kettlebell together, that let's say like in a goblet squat might allow us to sit back a little bit more and keep that good upright torso position. But the other thing is that it emphasizes a lot of core when we go into it. Anytime you're holding a weight in front of the body, you're having to resist that desire for your body to go forward. So I find that it brings a lot of core into the exercise, which is great in general for a lot of people. Might not be the best way to totally weight the legs, but for newer clients as well, you know, core is generally a big part of what we want to train. So I find that it's great for that.
