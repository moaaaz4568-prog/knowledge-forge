"Your large language model actually gets worse after every single message you send it, and that's because of this idea of context rot. And context rot means that for every single input that we add to an AI system, the more its context window grows, the worse it performs. Now, what is a context window?" — sources/S_ig_chase.h.ai_DTgT0vIkXED.md

# T_DTgT0vIkXED_02

"Now, a context window is essentially just the token budget for a large language model or an AI system. Every single word you send it and every single word it sends you back is essentially a single token, and the window is how many tokens it can spend. Something like this, which is Opus 4.5 from Claude, has 200, 000 tokens." — sources/S_ig_chase.h.ai_DTgT0vIkXED.md
