# G_yt_laJNhfk5JWQ_en — Claude code

## Term

In this video, Claude code is the coding tool the speaker uses to run a marketing agency doing over two hundred grand a month with an extremely tiny team, and it names the system that does the work, not a chat assistant on the side. The phrase appears 4 times, beside AI agents, onboarding, and automations, and the concrete move is to have Claude code build and maintain a custom internal app — onboarding a new client the moment they sign up, answering angry client messages, keeping dozens of automations running — while the speaker, a non-coder, only adds an AI agent to update it. Its use here is an operator, not a demo: the core app underneath everything in the business was completely built by Claude code, and the video walks through how it is maintained day to day.
